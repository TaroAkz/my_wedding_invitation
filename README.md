## ✨ Overview

**My Wedding Invitation** is a modern, responsive wedding invitation website built with **Vue 3**, **Vite**, and **Tailwind CSS**.  
It reimagines a traditional HTML + CSS wedding page into a clean, mobile-first experience — complete with a blurred background and a centered invitation frame designed for elegance and simplicity.

👉 **Live Demo:** [my-wedding-invitation-omega.vercel.app](https://my-wedding-invitation-ivory.vercel.app)

---

## 💡 Why This Project

- Modernized an old static invitation into a fast, component-based Vue 3 app
- Simplified deployment for easy sharing (e.g., send a link via message or QR)
- Built for reusability — can be adapted for other events or future weddings
- Inspired by the idea of blending design elegance with modern web performance

---

## 🌸 Features

- 📱 **Fully responsive** — optimized for both mobile and desktop
- 💎 **Blurred background aesthetic** for a premium visual feel
- ⚡ **Built with Vite** — instant dev server, lightning-fast builds
- 🎨 **Tailwind CSS** — easy customization of colors, fonts, and spacing
- 🧩 **Modular Vue components** for reusability
- 🧾 **Guest list support** via `guest.json`
- 🚀 **Deploy-ready** to Vercel, Netlify, or any static host

## 🚀 Getting Started

### Prerequisites

Make sure you have:

- Node.js **v16+**
- npm or yarn installed

### Installation

```bash
git clone https://github.com/TaroAkz/my_wedding_invitation.git
cd my_wedding_invitation
npm install
```
